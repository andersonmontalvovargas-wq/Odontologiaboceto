# Paquete para crear una nueva página web del consultorio

Todo lo que se sabe del Consultorio Dra. Vanesa Gutiérrez, listo para empezar una página nueva en otra conversación sin perder nada.

**Cómo usarlo:** abre una conversación nueva, adjunta esta carpeta (o el .zip) y pega el texto de `PROMPT-NUEVA-CONVERSACION.md`.

| Archivo | Qué tiene |
|---|---|
| `PROMPT-NUEVA-CONVERSACION.md` | Mensaje listo para pegar en la nueva conversación |
| `DATOS.md` | Datos del consultorio y de la doctora, con la fuente de cada uno |
| `datos.json` | Los mismos datos más todos los textos, en formato para programar |
| `TEXTOS.md` | Todos los textos de la página: primera pantalla, 8 tratamientos, doctora, primera cita, opiniones, 9 preguntas frecuentes, títulos y descripciones para Google |
| `FOTOS.md` | Fotos de referencia de Pexels (con enlace y descripción) y las reglas para usar fotos |
| `DISENO-Y-DECISIONES.md` | Lo que el cliente pidió y aprobó, las 5 propuestas ya hechas y qué gustó |
| `PENDIENTES.md` | Lo que falta pedirle o confirmarle a la doctora |
| `VERIFICACION.md` | Revisión dato por dato contra la conversación: qué dijo el usuario, qué quedó escrito y qué se dedujo |
| `REGLAS-DEL-PROYECTO.md` | Copia de las reglas del proyecto (CLAUDE.md) que debe cumplir cualquier página |
| `capturas/` | Inicio de las propuestas A a E en computador. Las rayas grises marcan dónde van las fotos (no cargaron al tomar la captura) |
